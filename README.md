Hospital Appointment & Management Portal

A full-stack web application designed to manage hospital operations and appointments. It provides separate dashboards for Admin, Doctor, Receptionist, and Patient, with role-based access and secure authentication.

Key Features

Patient and doctor management
Appointment scheduling and confirmation
Doctor schedule and medical record management
Staff account and consultation fee management
Payment verification
JWT authentication and role-based access control

Technology Stack

Backend: Python, FastAPI
Database: PostgreSQL
ORM: SQLAlchemy
Authentication: JWT
Frontend: HTML, Jinja2, CSS, JavaScript
Tools: Visual Studio Code, pgAdmin

Project Type: Full-Stack Web Application
